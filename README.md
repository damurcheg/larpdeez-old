# Личная образовательная платформа

Персональная веб-платформа для создания, редактирования и прохождения собственных
образовательных курсов в стиле Notion. Один пользователь, вход по одному паролю,
данные хранятся на сервере (SQLite) и синхронизируются между устройствами.

## Структура проекта

```
server/          Серверная часть (Node.js + Express)
  index.js       Точка входа — запуск HTTP-сервера
  app.js         Маршруты API, отдача статики, сессии/CSRF
  auth.js        Проверка пароля (scrypt), HMAC-сессии
  db.js          Хранилище SQLite (better-sqlite3)
public/          Клиентское SPA (без сборки, без фреймворков)
  index.html
  css/           Стили (светлая/тёмная темы)
  js/            Модули интерфейса, логики и работы с данными
data/            Файл базы данных platform.db (создаётся автоматически)
```

## Запуск на компьютере

Требуется Node.js 18+.

```bash
cd /workspace
npm install          # один раз, если node_modules отсутствует
npm start            # эквивалентно: node server/index.js
```

Сервер поднимется на порту 3000 (или значение переменной `PORT`):
`http://localhost:3000`

Если пароль ещё не был задан, при первом запуске создаётся временный
`admin123` — немедленно смените его в профиле (кнопка «Редактировать профиль»).

Данные сохраняются в `data/platform.db`. Чтобы не потерять их при переносе —
скопируйте этот файл или используйте экспорт резервной копии в настройках.

## Первый вход

1. Откройте адрес платформы в браузере.
2. Введите пароль (первый запуск — `admin123`).
3. Смените пароль в профиле.
4. Создайте курс, модули, дисциплины, темы и задания.
5. При желании назначьте один курс «главным» — он будет открываться
   автоматически на любом устройстве после входа.

Сессия живёт 30 дней, поэтому входить каждый раз заново не нужно.

## Как открыть с любого устройства

Платформа доступна по любому адресу, по которому «до неё дотянется» сеть.
Выберите подходящий вариант:

### Вариант A. Домашняя сеть (телефон/планшет/второй ноутбук дома)

1. Узнайте локальный IP компьютера с сервером, например:
   - Linux/macOS: `hostname -I` или `ifconfig`
   - Windows: `ipconfig` (IPv4-адрес, вида `192.168.x.x`)
2. Убедитесь, что сервер слушает все интерфейсы (в `server/index.js` вызов
   `app.listen(PORT)` без указания хоста слушает `0.0.0.0` — это так).
3. На любом устройстве той же Wi-Fi сети откройте:
   `http://192.168.x.x:3000`

### Вариант B. Доступ из интернета (любое устройство, любая сеть)

Локальный адрес не выйдет в интернет. Нужен публичный доступ — выберите одно:

1. **VPS / облачный сервер** (самый надёжный способ).
   - Скопируйте проект на сервер (`git clone` или `scp -r /workspace user@server:platform`).
   - `npm install && PORT=3000 node server/index.js`
   - Поставьте reverse-proxy с HTTPS (nginx + certbot / Caddy) и переменное
     окружение `PLATFORM_SECRET_SEED` (см. ниже).
   - Открывайте `https://ваш-домен.ru` с любого устройства.

2. **Туннель без сервера** (для быстрой проверки): Cloudflare Tunnel,
   ngrok, Tailscale Funnel и т. п. Пример:
   `npx cloudflared tunnel --url http://localhost:3000`
   выдаст публичный https-адрес.

3. **Tailscale** (приватная сеть между вашими устройствами): установите
   Tailscale на компьютер с сервером и на телефон — открывайте
   `http://<tailscale-ip>:3000` только со своих устройств, наружу ничего не торчит.

### Важно при доступе извне

- **HTTPS.** Без HTTPS браузер может помечать сайт как небезопасный, а cookie
  сессии отправляются без флага `Secure` только по http. За nginx/Caddy с
  сертификатом всё работает корректно (сервер сам определяет https по заголовку
  `X-Forwarded-Proto`).
- **Пароль.** Он проверяется на сервере через scrypt, но при входе по чистому
  http из интернета пароль летит открытым текстом — для интернета используйте HTTPS.
- **Бэкапы.** Регулярно выгружайте резервную копию (Настройки → Экспорт данных)
  и/или копируйте файл `data/platform.db`.

## Перенос данных между устройствами/серверами

- Через интерфейс: кнопка экспорта скачивает JSON-файл, импорт загружает его обратно.
- Физически: достаточно скопировать файл `data/platform.db` на новый сервер —
  все курсы, прогресс, события и настройки (включая хэш пароля) перенесутся.

## Переменные окружения

| Переменная              | Назначение                                                                 |
|-------------------------|-----------------------------------------------------------------------------|
| `PORT`                  | Порт HTTP-сервера (по умолчанию 3000)                                      |
| `PLATFORM_PASSWORD`     | Задать начальный пароль при первом запуске (иначе временный `admin123`)    |
| `PLATFORM_SECRET_SEED`  | Стабильный секрет для подписи сессий; нужен, если меняете пароль до первого входа или переносите данные без БД |

Пример запуска для продакшена:

```bash
PORT=3000 PLATFORM_SECRET_SEED="$(openssl rand -hex 32)" npm start
```

## Кратко: как пользоваться

- **Главная** — список курсов, прогресс, средний балл; справа календарь и планер.
- **Курс** — модули (завершённые уходят в сворачиваемый блок внизу), теги, прогресс.
- **Редактор курса** — drag-and-drop сортировка всех уровней, создание/удаление элементов.
- **Тема** — модальное окно: название, описание, дата (кастомный date picker), ссылки.
- **Задание** — критерии, отметка выполнения, оценка по единой шкале 1–5.
- **Финальный проект модуля** — включается в редакторе модуля: название, описание,
  срок сдачи, иконка, критерии, референсы; участвует в прогрессе и оценках.
- **Календарь** — компактный в сайдбаре + полная страница с неделями и событиями.
- **Профиль** — имя, аватар, баннер, смена пароля; единая шапка на всех страницах.
